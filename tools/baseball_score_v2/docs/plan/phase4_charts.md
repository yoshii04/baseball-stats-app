# Phase 4: グラフ・ビジュアライゼーション追加

## 状態: ✅ 完了

## 目的

Phase 3のテーブル表示に加え、グラフによる視覚的なデータ表現を追加する。
数字の羅列では見えにくいトレンドや傾向を直感的に把握できるようにする。

---

## 実装内容

### 1. 累積打率・OPS推移グラフ（分析画面）

**対象**: `AnalyticsView.vue`

**概要**: 現在のテーブル表示に加えて、折れ線グラフで推移を視覚化する。

**実装内容**
- 選手別の累積打率・OPS推移を折れ線グラフで表示
- X軸: 試合日、Y軸: 累積打率 / 累積OPS
- 複数選手を同一グラフ上に重ねて比較できる

**使用ライブラリ候補**
- Chart.js + vue-chartjs
- または Recharts（Vue対応版）

---

### 2. 打球方向グラフ（分析画面）

**対象**: `AnalyticsView.vue`

**概要**: 現在のテーブル表示に加えて、打球傾向を視覚化する。

**実装内容**
- 選手ごとの打球方向割合を横棒グラフで表示
- 右/右中/中/左中/左 の比率をカラーで区別
- 引っ張り傾向・逆方向傾向が一目でわかる

---

### 3. ダッシュボードへのグラフ追加

**対象**: `DashboardView.vue`

**概要**: チーム全体のパフォーマンストレンドをグラフで表示。

**実装内容**
- チーム打率の試合別推移グラフ
- 選手別本塁打数の棒グラフ

---

## 技術的な考慮点

- グラフライブラリは `vue-chartjs`（Chart.js ラッパー）を推奨
  - Vue 3 対応済み
  - Tailwind CSS との相性良好
  - `npm install vue-chartjs chart.js` で導入可能
- レスポンシブ対応（スマホでも見やすいサイズ調整）
- ローディング中はスケルトン表示またはスピナーを維持
