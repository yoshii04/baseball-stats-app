# Phase 5: 選手詳細ページ

## 状態: ✅ 完了

## 目的

選手一覧画面から選手をクリックすると、その選手の詳細な成績・分析を確認できる専用ページを追加する。
チーム全体の把握（Phase 3）から個人の深掘り分析（Phase 5）へと機能を拡充する。

---

## 実装内容

### 1. 選手詳細ページ（新規: `PlayerDetailView.vue`）

**ルート**: `/players/:id`

**概要**: 特定選手のシーズン全成績・推移を1ページで確認できる。

**実装内容**

#### ヘッダーセクション
- 選手名・所属チーム
- シーズン成績サマリー（打率・OPS・本塁打・打点 等）

#### 試合別成績テーブル
- 日付・対戦相手・打数・安打・2塁打・3塁打・本塁打・四死球・三振・盗塁・打率
- 試合ごとの成績一覧（時系列順）

#### 累積打率・OPS推移グラフ（Phase 4完了後）
- 試合を追うごとの累積打率・OPS折れ線グラフ

#### 打球方向チャート（Phase 4完了後）
- その選手の打球方向割合グラフ

---

### 2. 選手一覧からの遷移

**対象**: `PlayersView.vue`

**実装内容**
- 選手名をクリックで `/players/:id` へ遷移
- 選手行にホバーで遷移可能であることを示すスタイル追加

---

### 3. バックエンドAPI（必要に応じて追加）

既存APIで対応可能な範囲：
- `GET /api/players/{id}` → 選手基本情報
- `GET /api/players/{id}/stats` → 試合別成績・累積打率・OPS

必要に応じて追加検討：
- `GET /api/players/{id}/analytics` → 打球方向（選手単体）

---

## 画面遷移イメージ

```
選手成績一覧 (/players)
    ↓ 選手名クリック
選手詳細 (/players/:id)
    ├─ シーズンサマリー
    ├─ 試合別成績テーブル
    ├─ 累積推移グラフ（Phase 4後）
    └─ 打球方向グラフ（Phase 4後）
```
