# Phase 3: フロントエンド画面実装

## 状態: ✅ 完了（ブランチ: feature-func-score_v25）

## 目的

Phase 2で構築したフロントエンド基盤に、各画面の具体的なUIと機能を実装する。

---

## 実装対象画面

### 1. ダッシュボード（`DashboardView.vue`）

**概要**: アプリ起動時のトップ画面。チーム全体の状況を一目で把握できる。

**実装内容**
- サマリーカード（試合数・チーム打率・チームOPS・本塁打数）
- OPSランキングテーブル（上位10名）
- 年度セレクター連動（年度変更で全データ再取得）

**使用API**
- `GET /api/stats/season`
- `GET /api/stats/ranking`

---

### 2. 選手成績（`PlayersView.vue`）

**概要**: 全選手のシーズン成績を一覧で確認できる画面。

**実装内容**
- 成績一覧テーブル（試合数・打数・安打・1〜3塁打・本塁打・四死球・三振・盗塁・打率・出塁率・長打率・OPS）
- 選手名テキスト絞り込み
- OPS降順ソート
- 年度セレクター連動

**使用API**
- `GET /api/players`

---

### 3. 試合一覧（`GamesView.vue`）

**概要**: 試合の一覧表示と、試合ごとの選手別成績をモーダルで確認できる画面。

**実装内容**
- 試合一覧テーブル（日付・第N試合・ホーム・アウェイ）
- 月フィルター・年度セレクター連動
- 試合行クリックで詳細モーダル表示
  - モーダル内: 選手別成績テーブル（打数・安打・2塁打・3塁打・本塁打・四死球・三振・打率）

**使用API**
- `GET /api/games`
- `GET /api/games/{id}`

---

### 4. 分析（`AnalyticsView.vue`）

**概要**: 打球傾向や成績推移を分析できる画面。タブで切り替え。

**実装内容**
- タブ切り替え（打球方向 / 累積成績推移）
- 打球方向テーブル（右/右中/中/左中/左 の本数と割合%）
- 累積打率・OPS推移テーブル（選手選択→試合ごとの累積推移を表示）
- 年度セレクター連動

**使用API**
- `GET /api/analytics/hit-direction`
- `GET /api/analytics/batting-trend`
- `GET /api/players`（選手選択プルダウン用）
