# スコアの写真を CSV にする手順

スコアボードの写真（PNG など）を、`write_score.py` が読み込めるスコア CSV に変換する手順です。
画像の読み取りは Claude の `baseball-score-csv` スキルで行い、読み取れない箇所は人が確認して確定します。

## 手順

1. スコアボードの画像を Claude に渡し、次のように依頼する。

   ```text
   このファイルは、野球のスコアです。
   baseball-score-csv のスキルで CSV ファイルを作成してください。
   ファイル名: baseball_score_2026-03-29_2.csv
   保存先: tools/baseball_score_v2/data/scores/
   ```

2. 判読できない箇所について、Claude から確認の質問が来る。回答して確定させる。

   ```text
   Claude: 自チームの6回：0 でよいですか？
   あなた: はい。
   Claude: 相手チームの6回：10 でしょうか？（スコアボードに 10u のような記載があります）
   あなた: はい。
   ```

   チーム名が読み取りにくい場合も、同様にチーム名を直接指定して確定する。

3. 出力された CSV を目視で確認し、`write_score.py --csv-dir data/scores` で書き込む
   （[運用手順](operations.md) の「スコアをExcelに書き込む」を参照）。

## ファイル名の規則

`*_YYYY-MM-DD_N.csv`（例: `baseball_score_2026-03-29_2.csv`）

試合入力ファイル（`YYYY-MM-DD_相手チーム_N.txt`）と、**日付と試合番号 N** で自動的に対応づけます
（`write_score.py` の `find_matching_csv`）。日付・試合番号が一致しないと別の試合として扱われます。

## CSV の形式

```csv
チーム名,1,2,3,4,5,6,7,8,9,合計
自チーム名,2,0,4,1,1,0,2,1,2,13
相手チーム名,3,0,2,0,0,2,0,0,1,8
```

- 1 行目はヘッダー。2 行目が上段（先攻）、3 行目が下段（後攻）として Excel に書き込まれる。
- サヨナラ勝ちなどで合計が `2X` のように `X` で終わる場合は、サヨナラとして扱われる。
